    What is carried over?

    Comfy Cloud receives a real workflow JSON when you import the downloaded file. For reference-based starter templates, add your own media directly in Cloud and replace example prompts and inputs. Supported text-only recipes can embed your prompt here without any local engine or Python environment.

    Civitai receives a prompt only when you paste it there. Its generation brief is a text checklist, not a ComfyUI workflow import. Open the referenced models or original example to check which resources can run on Civitai. Shared prompts and model availability do not guarantee the same image.
