02 / CHECK YOUR RECIPE

Only get what you need.

ComfyUI says models are missing?

Import the workflow JSON into ComfyUI. On the setup-error notice, choose View details, then Issues → Missing Models. Review the listed filenames and folders. Use Download for one file or Download all for the recipe; large models may take several gigabytes.

These controls were checked with the Z-Image graph in a separate ComfyUI installation with empty model folders. If your edition downloads through the browser, save each file in its listed folder. Refresh the model list or restart ComfyUI, then check your recipe here again.

03 / OPTIONAL LOCAL AI

A guide for your next idea.

Open Studio guide on any page to ask about tools or build a suggested workflow chain. Guided matching works immediately. Conversational answers use a local Ollama chat model that you choose.

  1. Install and start Ollama ↗.
  2. Install a chat model through Ollama. A smaller model makes a useful starting point; download sizes and licenses vary.
  3. Open Studio guide → Local AI & connections → Refresh models, then select your model.

The assistant runs text inference on CPU and unloads its model after answering. It can read supported workflows and local ComfyUI queue status. It cannot start jobs, install files or spend credits.

Connect an external AI agent with MCP

Use this same studio from Codex, Claude or another MCP client. Register node /your/full/path/scripts/frameforge-mcp.mjs. Discovery and inspection are read-only by default. Add --allow-writes to prepare graphs, generate locally, inspect results and manage film projects. Add --start-studio to launch the website backend when needed.

Use --open-weights-only to restrict the agent to reviewed local pipelines. The website toggle controls its own persistent profile; npm run start:open locks that profile. No automatic model downloads, shell access, paid requests or creative approval tools are exposed.

Set FRAMEFORGE_IMPORT_ROOT to a folder of media you authorize the agent to read. MCP connections belong to your client; they are not inherited by the website assistant. Codex & Claude setup, tools and examples ↗

SHARE THE LAYER, KEEP YOUR FILES

Made for a fresh install.

The GitHub source package includes the interface, workflow JSON and model download manifests. Your models, Python environments, generated media, personal settings and API keys stay outside it. Start the website with Node.js 22 or later; connect ComfyUI when you are ready.

Standalone speech, masking and video finishing also need their documented local Python tools. A connected ComfyUI alone does not install those processors.
