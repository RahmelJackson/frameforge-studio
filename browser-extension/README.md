# Frameforge Quick (browser extension)

Right-click any image on the web → **Frameforge** → remix it, select part of it with SAM 3, make it a (vertical) video, animate it with LTX 2.5, use it as a character for identity swap, or turn it into a 3D layout or 3D model. The image goes straight from your browser to your own studio.

Install (Chrome, Edge, Brave): open `chrome://extensions`, turn on Developer mode, choose **Load unpacked** and pick this folder. The default studio is `http://127.0.0.1:4317`; click the toolbar icon to change it (for example to your PC's Tailscale address when you are away).

Use images you have the right to use, and respect the people in them.
