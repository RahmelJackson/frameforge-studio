# Local speech, transcription, translation and lip-sync dependencies

Model download URLs, immutable revisions, byte sizes and SHA-256 hashes are in `audio-models.lock.json`. The installed files total approximately 5.04 GB. Python packages installed in the separate audio environment are pinned in `requirements-audio.lock.txt`; installed package LICENSE/NOTICE metadata remains present.

- Kokoro-82M model: https://huggingface.co/hexgrad/Kokoro-82M (Apache-2.0). ONNX adapter and release: https://github.com/thewh1teagle/kokoro-onnx (MIT); release `model-files-v1.1`, full precision v1.0 model and its 54-voice pack. The app exposes five preset voices in English/Spanish. Phonemization uses phonemizer and the bundled eSpeak NG loader; these components have their own GPL-family terms. This is local speech synthesis, not voice cloning.
- Faster-Whisper: https://github.com/SYSTRAN/faster-whisper (MIT), using CTranslate2 (MIT). Small multilingual Whisper conversion: https://huggingface.co/Systran/faster-whisper-small; upstream Whisper: https://github.com/openai/whisper (MIT).
- English-to-Spanish translation: https://huggingface.co/Helsinki-NLP/opus-mt-en-es (Apache-2.0 model card), via Marian in Transformers (Apache-2.0). Automatic translation has only this installed direction. The earlier Argos package URL returned 403; no Argos model is installed or used.
- MuseTalk 1.5: https://github.com/TMElyralab/MuseTalk and https://huggingface.co/TMElyralab/MuseTalk (MIT). The pinned upstream code revision is in `audio-source.lock.json`; full upstream license and downloaded model cards are retained in `audio-model-notices/`. Our adapter follows the official VAE/UNet/Whisper conditioning and positional encoding, with MediaPipe face crops and a narrower mouth compositor replacing the original detector/parser stack. It is an adapted pipeline and does not claim upstream quality parity. The stock MMLab, face parser and SyncNet evaluation models are not installed.
- VAE: https://huggingface.co/stabilityai/sd-vae-ft-mse (MIT, as listed by the MuseTalk notice); Whisper-tiny: https://huggingface.co/openai/whisper-tiny (MIT). Diffusers and Transformers: Apache-2.0. MediaPipe uses the previously pinned vision environment; see `VISION-NOTICES.md`.
- Audio/video I/O: PyAV (BSD-3-Clause), SoundFile (BSD-3-Clause, with separately licensed libsndfile), SciPy/NumPy (BSD-family), Pillow (HPND). FFmpeg filters and codecs follow the licenses of the installed PyAV build.

The audio environment has its own packages and reads the existing engine's CUDA Torch installation through a fallback path. Setup does not install packages into or alter the engine environment. Inference loads local files only and does not call a hosted media API. Retain all relevant component notices when distributing a packaged application; this summary does not replace the original licenses.


## LatentSync comparison added October 21, 2026

Round ten uses trimmed official filmed `assets/demo2_video.mp4` and `assets/demo3_video.mp4` fixtures from the same pinned source archive, with locally extracted soundtrack segments. Archive members and hashes are retained in `evidence/acceptance-round10/source-fixtures.json`; the project README describes its demo actors as contracted models. They are evaluation fixtures, not user recordings or production voices. The marked object coverage example is a synthetic composite. An existing FaceFusion XSeg CPU probe was rejected for false positives and is not part of the lip-sync pipeline. No new model/package was installed in round ten.

- Official source: https://github.com/bytedance/LatentSync (Apache-2.0). Immutable revision, source archive/per-file hashes and official ByteDance/LatentSync-1.6 weights are in `latentsync.lock.json`. The downloaded source includes the original license; retain it when distributing.
- The local adapter uses upstream UNet/Whisper conditioning, fixed 20 steps and guidance 1.5, the existing pinned SD VAE, upstream affine geometry with MediaPipe eyebrow/nose points, chunked/sliced VAE processing and our narrower mouth compositor. PyAV replaces shell/Decord I/O. It does not claim unmodified upstream preprocessing or benchmark quality. Inference is offline.
- The separate `runtime/latentsync-env` overrides its own Diffusers/NumPy/OpenCV packages and reads the existing audio/engine Torch libraries. No existing environment is modified. Package pins: `requirements-latentsync.lock.txt`; model/runtime storage remains on D:. Rebuild using `scripts/setup-latentsync.ps1`.
- Diagnostic SyncNet architecture and auxiliary checkpoint are pinned in `lipsync-eval.lock.json`. Upstream source credits https://github.com/joonson/syncnet_python (retain its applicable upstream terms/attribution when distributing). Our diagnostic uses the released architecture, MFCC features and offset-distance premise with fixed MediaPipe face boxes replacing S3FD. It checks ±8-frame audio shifts; confidence is uncalibrated and is not individual phoneme accuracy.
